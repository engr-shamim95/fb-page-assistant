# Facebook AI Agent Bot - সেটআপ এবং পরিচালনার নির্দেশিকা

এই নির্দেশিকায় ধাপে ধাপে বলা হয়েছে কীভাবে আপনি আপনার Facebook AI Agent Bot-টি নিজের কম্পিউটারে রান করবেন এবং Facebook-এর সাথে যুক্ত করবেন।

## ধাপ ১: প্রয়োজনীয় রিকোয়ারমেন্টস (Prerequisites)
১. আপনার কম্পিউটারে **Python** ইন্সটল থাকতে হবে।
২. একটি **Facebook Page** এবং [Facebook Developer](https://developers.facebook.com/) অ্যাকাউন্টে একটি App থাকতে হবে।
৩. Google AI Studio থেকে একটি **Gemini API Key** সংগ্রহ করতে হবে।
৪. লোকাল সার্ভার লাইভ করার জন্য **Ngrok** সফটওয়্যার থাকতে হবে।

## ধাপ ২: এনভায়রনমেন্ট সেটআপ (.env ফাইল)
আপনার প্রজেক্ট ফোল্ডারে `.env` ফাইলটিতে নিচের তথ্যগুলো সঠিকভাবে বসানো আছে কিনা নিশ্চিত করুন:
```env
VERIFY_TOKEN=আপনার_পছন্দের_যেকোনো_একটি_গোপন_শব্দ (যেমন: my_secret_token_123)
PAGE_ACCESS_TOKEN=ফেসবুক_ডেভেলপার_পোর্টাল_থেকে_পাওয়া_পেইজ_টোকেন
GEMINI_API_KEY=গুগল_জেমিনি_এপিআই_কি
```

## ধাপ ৩: লাইব্রেরি ইন্সটল করা
টার্মিনাল বা কমান্ড প্রম্পট ওপেন করে আপনার প্রজেক্ট ফোল্ডারে (`i:\AI Agent`) যান এবং নিচের কমান্ডটি রান করে প্রয়োজনীয় লাইব্রেরিগুলো ইন্সটল করে নিন:
```bash
pip install -r requirements.txt
```

## ধাপ ৪: বট রান করা (Local Server)
এবার আপনার বটটি চালু করার জন্য টার্মিনালে রান করুন:
```bash
python app.py
```
আপনার সার্ভারটি `http://localhost:8080` পোর্টে চালু হবে। কাজ শেষ না হওয়া পর্যন্ত এই টার্মিনালটি এভাবেই খোলা রাখুন।

## ধাপ ৫: Cloudflare Permanent Tunnel এর মাধ্যমে সার্ভার লাইভ করা
Facebook Webhook যুক্ত করার জন্য একটি সিকিউর HTTPS URL প্রয়োজন। যেহেতু আপনি Cloudflared Permanent Tunnel ব্যবহার করেন, তাই আপনার লোকাল সার্ভারকে ইন্টারনেটে উন্মুক্ত করার জন্য আমি আপনার `config.yml` ফাইলে সব কনফিগারেশন সেটআপ করে দিয়েছি।

* **আপনার ডোমেইন:** `https://ai.engrshamim.shop`
* **লোকাল পোর্ট:** `http://localhost:8080`

যেহেতু আপনার Cloudflared ব্যাকগ্রাউন্ডে চলছে, তাই নতুন করে রান করার প্রয়োজন নেই (তবে কনফিগারেশনটি কাজ করানোর জন্য আপনার কম্পিউটারটি একবার রিস্টার্ট করতে হতে পারে, অথবা সার্ভিস রিস্টার্ট দিতে পারেন)।

## ধাপ ৬: Facebook Webhook সেটআপ
১. Facebook Developer পোর্টালে আপনার App-এ যান।
২. **Messenger** অপশনের অধীনে **Settings** সেকশনে গিয়ে **Webhooks** সেটআপ করুন।
৩. **Callback URL** এর জায়গায় আপনার ডোমেইনটির শেষে `/webhook` বসিয়ে দিন (অর্থাৎ: `https://ai.engrshamim.shop/webhook`)।
৪. **Verify Token** এর জায়গায় আপনার `.env` ফাইলে দেওয়া `VERIFY_TOKEN` টি দিন।
৫. **Verify and Save**-এ ক্লিক করুন।
৬. Webhook সাবস্ক্রিপশনে `messages` ফিল্ডটি সিলেক্ট করে দিন।
৭. সবশেষে আপনার পেইজটি (Page) এই অ্যাপের সাথে লিংক (Subscribe) করুন।

## ধাপ ৭: টেস্টিং
সবকিছু ঠিকঠাক থাকলে আপনার Facebook Page-এ মেসেজ দিন। আপনার প্রজেক্টের টার্মিনালে দেখতে পাবেন মেসেজ রিসিভ হয়েছে এবং বটটি Gemini AI ব্যবহার করে স্বয়ংক্রিয়ভাবে রিপ্লাই দিচ্ছে। 

### কিছু গুরুত্বপূর্ণ টিপস:
